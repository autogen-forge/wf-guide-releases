# WF Guide

워프레임 다음 할 일을 알려 주는 게임 위 오버레이 프로그램입니다.
내 계정 상태를 기준으로 퀘스트, 모드, 마스터리, 월드 시간, 일일 목록을 한 창에 모아 보여 줍니다.

## 다운로드

**[Windows용 설치 파일 받기](https://github.com/autogen-forge/wf-guide-releases/releases/latest/download/WF-Guide-setup.zip)**

- Windows 10 · 11
- 버전별 파일과 변경 내역은 [Releases](https://github.com/autogen-forge/wf-guide-releases/releases)에서 볼 수 있습니다.
- 설치 없이 쓰는 단독 실행 파일은 같은 릴리스의 `WF-Guide-portable.zip`입니다.
- zip의 압축을 풀고 안의 `.exe`를 실행하세요. 서명되지 않은 새 파일이라 처음엔 Windows가 경고를 띄울 수 있습니다 (추가 정보 → 실행).

## 들어 있는 것

- **대시보드**: 지금 할 일, 월드 시간, 다음 메인 퀘스트
- **진행**: 메인 퀘스트 타임라인, 시작 조건, 정션, 스틸패스 진행률
- **마스터리**: 다음 랭크까지 남은 양, 랭크를 덜 올린 장비
- **모드 · 아케인**: 없는 핵심 모드와 파밍처, 강화 우선순위
- **제작**: 파운더리 재료 확인, 렐릭
- **시세 · 리벤**: warframe.market 시세, 리벤 평가
- **월드 · 일일**: 시터스·오브 밸리스·캄비온 드리프트·지구·자리만 낮밤, 소티, 나이트웨이브, 균열, 바로 키티어

오버레이는 항상 위에 뜨는 반투명 창이고, 클릭은 게임으로 통과시킬 수 있습니다.
오버레이를 여러 개 만들어 위젯 구성, 위치, 크기, 투명도를 각각 정할 수 있습니다.

## 시작하기

1. 설치 파일을 실행합니다.
2. 처음 한 번 「게임 데이터 받기」를 누릅니다. (약 25MB)
3. 워프레임에 로그인한 상태에서 「게임에서 자동 동기화」를 누르거나, 설정에서 닉네임을 넣어 공개 프로필을 불러옵니다.
4. `Ctrl` `Shift` `W`로 오버레이를 띄웁니다.

워프레임 화면 모드를 **테두리 없는 전체화면**으로 바꿔야 오버레이가 게임 위에 보입니다.

## 단축키

| 키 | 동작 |
|---|---|
| `Ctrl+Shift+W` | 오버레이 보이기 / 숨기기 |
| `Ctrl+Shift+E` | 클릭 통과 켜기 / 끄기 |
| `Ctrl+Shift+Q` | 누르는 동안만 클릭 통과 해제 |
| `Ctrl+Shift+M` | 본창 열기 |
| `Ctrl+Shift+R` | 화면의 리벤을 캡처해서 평가 |

## 주의

**자동 동기화는 안전하다고 보장할 수 없습니다.**
실행 중인 `Warframe.x64.exe`의 메모리에서 로그인 세션 값을 찾아 DE 서버에서 인벤토리를 받아 옵니다.
게임 파일을 수정하거나 코드를 주입하지 않고 읽기만 하지만, DE의 약관에서 허용한 방식이 아니라서 계정이 제재를 받을 수 있습니다.
사용은 사용자의 선택이고 그로 인한 불이익은 개발자가 책임지지 않습니다. 설정에서 끌 수 있고, 끄면 공개 프로필과 수동 체크만으로도 쓸 수 있습니다.

개발자 서버는 없고 인벤토리·프로필·설정은 내 PC에만 저장됩니다. 사용 기록이나 분석 데이터는 수집하지 않습니다.

## 알려진 한계

- 퀘스트 순서 일부는 확인이 필요합니다 (「순서 확인 필요」로 표시).
- 마스터리 남은 양은 장비 마스터리만 계산합니다. 실제로는 이보다 적게 남아 있습니다.
- 장비 추천은 랭크·요구 MR·프라임 여부 기준의 단순 점수입니다.
- Windows에서만 동작합니다.
